## 1. 三个概念（10 min）

### 什么是 FPGA

- 一颗可以"烧录电路"的芯片——你写的代码不是"程序"，是"电路接线图"
- 和 CPU 的区别：CPU 一条一条执行指令；FPGA 所有电路**同时工作**（并行）
- 我们的芯片：安路 PH1P35MDG324，国产，约 4 万个逻辑单元
- 工具链：安路 TD 6.2.1（类似 Vivado/Quartus，但只支持安路芯片）

### 什么是"实时图像处理流水线"

- 摄像头每秒吐出 60 张图（1280×720 像素）
- 每个像素要经过"流水线"处理：去马赛克→白平衡→颜色空间变换→阈值→平滑→找目标
- 流水线 = 像工厂传送带，每个"工位"只做一件事，像素从前往后流
- 我们的流水线约 10 个工位，处理延迟 ≈ 3~5 帧（约 50~80ms）

### 什么是"闭环控制"

- 摄像头装在电机云台上
- 画面里目标偏离中心 → FPGA 算出偏差 → 输出 PWM 信号 → 电机转 → 摄像头跟着转
- 目标回到画面中心 → 偏差为零 → 电机停
- 整个回路每帧执行一次，人眼看是"自动跟踪"

## 3. 你们要学什么（15 min）

### 三层知识，按需学习

| 层 | 学什么 | 为什么 | 深度 |
|----|--------|--------|------|
| **必须会** | Verilog 读写、TD 工具操作、仿真跑通 | 不会就没法调试和上板 | 能看懂、能改参数、能跑仿真 |
| **应该懂** | 图像处理流水线、跨时钟域、I2C/UART 协议 | 调试时知道"问题在哪一级" | 理解原理，能画数据流图 |
| **了解即可** | SoC 架构、DDR2 控制器、HDMI 编码 | 官方黑盒，不需要改 | 知道它存在、接口是什么 |

### 必须会的那层，具体学什么

| 知识点 | 对应代码 | 学到什么程度 |
|--------|----------|-------------|
| Verilog 基础语法 | 所有 `.v` 文件 | 看懂 always/assign/reg/wire/module |
| 阻塞 vs 非阻塞赋值 | `gimbal_ctrl.v`（有真实 bug 教训） | 知道 `=` 和 `<=` 的区别 |
| 有符号运算陷阱 | `tb_closed_loop.v`（模型跑飞的教训） | 知道什么时候加 `$signed` |
| 复位 discipline | `tpg_720p.v`（计数器忘进复位导致 X 污染） | 每个寄存器都必须有复位值 |
| 跨时钟域 | `pulse_sync.v` / `cdc_4phase.v`（仅 100 行） | 知道为什么不能裸跨 |
| 参数 vs 硬编码 | 所有模块的 `parameter` | 知道怎么改分辨率/阈值 |
| 仿真怎么跑 | `tools/run_all.py` | 会跑回归、看 PASS/FAIL |
| Python 金标准 | `tools/golden_model.py` | 会改阈值参数并重新生成向量 |

### 不需要学的（有人写好了）

- MIPI D-PHY 接收、DDR2 控制器、HDMI 编码（官方黑盒，加密或极复杂）
- I2C 主控（官方 uii2c 模块，只需会用）
- AES/加密相关（不在本赛题范围）
