## 4. 学习路线（10 min）

按"先跑通再理解"原则，给每人一条最小学习路径：

### 如果你负责上板（A 组）

```
第 1 天：TD 6.2.1 打开例程工程 → 综合 → 下载 → LED 闪烁
第 2 天：接摄像头 → 跑 Lab1 → HDMI 出图
第 3 天：读 IF-DDR.md → 理解视觉分支挂载点（isp_top 输出级）
第 4 天：挂 detect_top → ChipWatcher 抓 t_valid/tick
第 5 天：挂 osd_track → 屏幕出现 TRK0 文字
```

关键文档：
- `SWUG101_TangDynasty Getting-Started`（TD 操作最短路径）
- `04_embedded/README_分工与移交.md`（挂载清单）
- `06_interfaces/current/IF-DDR.md`（挂载点与资源预算）

### 如果你负责算法（B 组）

```
第 1 天：python tools/run_all.py → 确认 15/15 全绿
第 2 天：读 tools/golden_model.py（全项目算术真值，~200 行）
第 3 天：读 03_vision/step2/02_技术文档（检测链每一级做什么）
第 4 天：改一个阈值 → 跑回归看变化 → 理解金标准-RTL 锁步关系
第 5 天：读 03_vision/step2/04_迭代文件（v1 到 v7 的 7 轮排错过程）
```

### 如果你负责云台（C 组）

```
第 1 天：读 05_gimbal/README + IF-SERVO-PWM.md
第 2 天：组装云台 + 独立供电 + 共地确认
第 3 天：FPGA 输出固定 1500µs → 舵机回中 → 万用表/示波器验证
第 4 天：读 03_vision/step3/02_技术文档（控制律/增益整定/发散教训）
第 5 天：配合 A 组联调（duty 方向/死区/极性校验）
```

## 6. 风险与注意事项（5 min）

| 风险 | 说明 | 对策 |
|------|------|------|
| 例程时序不收敛 | 官方已知现象，不代表工程有问题 | 预留余量，视觉逻辑 <3% LUT |
| 舵机从板载取电 | 画面闪/板复位/烧写中断——**看起来是软件 bug 实则是电源** | 第一天就接独立 5V |
| AWB 拉动颜色 | 检测阈值漂移 | 锁曝光 / 切阈值组（8 组已备） |
| 例程不是赛题附件 | 官方 Q&A 明确仅供学习 | 自己收敛时序，不指望例程完美 |
| 代码不在 Git | 多人协作冲突 | 建仓库，每次改后跑回归再 push |
| I2C ACK 位相未收敛 | BFM 仿真遗留 | 上板用逻辑分析仪对照真机波形 |
