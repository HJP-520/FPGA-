## 3. 日常操作

### 3.1 跑全量回归（任何改动后必做）

```bash
cd /d/fpga-ptz-tracker/tools
python gen_vectors.py      # 改了向量/场景/参数时
python run_all.py          # 全量 18 TB，约 4 分钟；期望输出「汇总: 18/18 PASS」
```

单跑：`python run_all.py tb_bin_smooth tb_detect_chain`
日志：`03_vision/step4_osd_integration/04_迭代文件/测试运行_<时间戳>.log`

### 3.2 改算法参数（阈值/分辨率）

1. 改 `tools/golden_model.py`（HSV_PRESETS / IMG_W/H / MIN_PIXELS）
2. 同步 RTL：`hsv_threshold.v` 的 case 表、各模块 `IMG_WIDTH/IMG_HEIGHT` 参数
3. `python gen_vectors.py && python run_all.py` 全绿后改完

### 3.3 换目标颜色

改 `HSV_PRESETS` 组 0（当前红色：H∈[335,25] 环绕、S≥80、V∈[60,255]）。
现场标定：把目标放镜头前截图 → Python 跑 `rgb_to_hsv` 看分布 → 定窗 → 同步 RTL。
上板后用按键切 8 组预置（阈值表已内置红/绿/蓝/橙/青/品红/白/黑）。

### 3.4 改云台参数（现场整定后）

`gimbal_ctrl.v` 与 `vision_top.v` 的参数（两处一致）：KP_X/KP_Y（Q8.8）、
DZ_X/Y、SLEW_US、SERVO_MIN/MAX_US、INVERT_X/Y。
**改完必须跑 `tb_closed_loop`**（相机-舵机模型会告诉你是否发散）：

```bash
python run_all.py tb_closed_loop   # 期望 "LOCKED: settle_frame=NN"
```

增益安全线：`Kp[µs/px] × 0.18[°/µs] × (1280/FOV)[px/°] × (1+延迟帧数) < 1`。

## 4. 上板移植（给嵌入式/联调，逐步）

1. TD 6.2.1 新建工程（HX1P35A），导入例程 Lab1 全部源码与约束
2. 加编译 `03_vision/*/03_project/rtl/` 下全部可综合文件
   （**排除** `sim_video_src.v`、`frame_dump24.v`——仿真专用）
3. `design_top_wrapper.v`：按 `04_embedded/README_分工与移交.md` 挂载
   `vision_top`（输入接 isp_top 输出级；pwm 输出接 40Pin DC3 两脚）
4. OSD：按 IF-OSD A/B 方案二选一（推荐并入 hdmi_mixer 像素 mux）
5. `pin.adc` 加 2 个 PWM 脚约束；50MHz 时钟域确认
6. 综合 → 查时序报告（视觉逻辑 <3% LUT，预期无碍）→ 上板
7. 验收顺序见 `04_embedded/README` 的联合验收清单

## 5. 演示脚本（答辩/验收）

1. 上电（固化 bit）→ 云台回中，OSD 显示 `TRK0 LOST`
2. 红色目标入画 → OSD 变 `TRK0 LOCK X..Y..`，十字/框跟踪，云台跟随（约 0.6s 锁定）
3. 快速甩目标 → 云台平滑跟随不摆头（Kp 已按稳定域整定）
4. 遮挡目标 2 秒 → 云台保持不动，OSD 显示 LOST（丢失策略=保持）
5. 按键切阈值组 → OSD 组号变化（TRK0→TRK1…），换颜色目标照样锁

## 6. 常见问题（FAQ）

| 现象 | 原因 | 处置 |
|------|------|------|
| ModelSim 打不开工程/编译错"sqlite" | 中文路径 | 工程文件目录保持 ASCII |
| 仿真 100% 失配 | hex 向量字段宽度与 reg 位宽不符 | 检查生成器 %0NX 与 TB reg 位宽（教训见迭代记录 #4/#9） |
| OSD 永远 LOST | 68bit 包位偏移不一致 | 对照 IF-VISION.md 检查 vision_top/osd_track 两端 |
| 云台不动 | 目标包 valid=0 或 CDC 未交付 | 先看 OSD 文字（LOCK 才说明包通了），再查 tick |
| 云台朝反方向 | 极性 | INVERT_X/Y 参数取反 |
| 云台持续摆头 | 回路增益超 1 | 降 Kp；公式见 IF-SERVO-PWM |
| 画面闪/板复位 | 舵机从板载取电 | 独立 5V 供电（硬件问题伪装成软件问题） |
| 换光照后检测漂 | AE 拉动颜色 | 锁曝光 / 切阈值组 / 现场标定 |
