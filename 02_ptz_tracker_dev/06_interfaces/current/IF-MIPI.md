# IF-MIPI 视频输入接口（v1.0.0）

## 定位

视觉方向**不直接接触 MIPI 物理层**。MIPI D-PHY 接收、CSI-2 解包（`raw10_unpacket_2lane.v`）、
去马赛克（`demosaic`）、自动白平衡（`awb`）全部属于嵌入式方向维护的官方例程代码
（`user_source/hdl_source/isp/`、`uiisp_beta/`）。视觉方向消费的是 **AWB 之后**的像素流。

## 视觉方向取得的流（挂在 `isp_top` 输出级）

| 信号 | 方向 | 位宽 | 含义 |
|------|------|------|------|
| `I_tdata` | → 视觉 | 96 | 4 像素/拍 RGB888：`pix0=[95:72] pix1=[71:48] pix2=[47:24] pix3=[23:0]`，每像素 `{R,G,B}` |
| `I_tvalid` | → 视觉 | 1 | 数据有效（仅有效像素拍，无消隐拍） |
| `I_tuser` | → 视觉 | 1 | 帧起始（每帧第一拍置 1） |
| `I_tlast` | → 视觉 | 1 | 行尾（每行最后一拍置 1） |
| `O_tready` | ← 视觉 | 1 | 视觉旁路恒 1（**窃流语义：绝不反压主线**） |

## 关键约定（两侧共同遵守）

1. **格式**：AWB 之后为 RGB888（例程 `raw8_to_rgb888`/demosaic 输出经 AWB 归一化）。
2. **节拍**：beat 率 = 像素率/4。720p60 有源像素率 55.3Mpx/s，beat 率 13.8M/s；
   在 74.25MHz 域内约每 4 拍 1 个 beat（1/4 占空）。TPG 与仿真源已按此占空生成。
3. **几何**：1280×720，行主序，`tuser` 帧首、`tlast` 行尾；宽为 4 的倍数（4-ppc 打包无残拍）。
4. **挂载方式**：`detect_top.v` 为**纯旁路分支**——直通输出与输入逐拍一致（TB 断言），
   不修改、不反压主线；主线照常 `data_96bit_to_128bit` → DDR2。摄像头故障时视觉分支无输出但不阻塞显示。

## 相机（嵌入式配置，视觉只读约定）

- 型号：Smartsens SC500CS（赛道唯一允许 SC500/SC520CS），2-Lane MIPI，10/8bit。
- 寄存器配置：嵌入式维护 `uics500reg_720p60.v`（1280×720@60）。**改分辨率必须同步通知视觉方向**改 `IMG_WIDTH/IMG_HEIGHT`。
- 曝光/增益：AE 相关（`uics500regAE.v`、`SC500GainTbl.v`）归嵌入式。**视觉已知风险**：AE 拉动会改变目标颜色 →
  演示前建议锁定曝光（视觉方向在《技术文档》中给出了现场标定流程与 8 组阈值备选）。

## 仿真替代物（视觉方向提供）

| 模块 | 用途 |
|------|------|
| `tpg_720p.v` | 板载无相机演示源：8 竖条（灰阶×4/蓝/绿/深绿/深蓝，全部避开红色阈值窗）+ 参数化红块（可被云台模型驱动） |
| `sim_video_src.v` | 回放 Python 生成的确定性场景（仅仿真） |
