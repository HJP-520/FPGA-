# IF-DDR 帧缓存接口（v1.0.0）

## 视觉方向与 DDR2 的关系：**零耦合（旁路窃流）**

 DDR2 帧缓存控制器（`ph1p35_ddr/**`，嵌入式方向维护）负责：
- 写路径：ISP 输出经 `data_96bit_to_128bit` → 128bit FIFO → DDR2（`video_in.v`）
- 读路径：DDR2 → HDMI 显示（`video_out.v` → `hdmi_mixer.v`）

**视觉检测分支不占用 DDR2 带宽、不修改帧数据**。挂载点：

```
isp_top ──96bit AXI-S──┬── data_96bit_to_128bit ──> DDR2（主线，原封不动）
                       └── detect_top（视觉窃流分支）→ 目标包
```

- `detect_top` 输入来自 `isp_top` 输出级的同一拍数据（并线，非串插入）
- `O_tready` 恒 1，不反压；直通输出与输入逐拍一致（TB 断言 `passthru_mism=0`）
- 视频主线的时序、带宽、乒乓切换全部保持例程原样 → **嵌入式方向无需为视觉改动任何 DDR 逻辑**

## 帧同步约定

- 视觉以流内 `tuser`（帧首）/`tlast`（行尾）定界，不读 DDR 控制器的帧指示
- 检测结果锁存在帧末消隐窗口内完成（除法 ~70 拍 @74.25MHz ≈ 0.94µs ≪ 消隐 45 行 ≈ 0.61ms）
- 若嵌入式未来改为 1080p30（`uics500reg_1080p30.v`），视觉仅需改 `IMG_WIDTH/IMG_HEIGHT`
  参数（1280×720→1920×1080），逻辑结构不变；**分辨率变更须提前一个迭代通知视觉方向**

## 嵌入式需知的视觉资源占用（PH1P35 资源预算）

| 模块 | 估算 | 备注 |
|------|------|------|
| 检测链（HSV/阈值/平滑/质心） | < 1500 LUT，2 个 1280×1bit dis-RAM | 1-ppc，时序余量大 |
| OSD 叠加 | < 800 LUT + 字库 ROM（~0.5 Kbit） | 挂显示侧 |
| 云台控制 + PWM | < 300 LUT | 50M 独立域 |
| 合计 | **< 3% LUT** | 35K LE 器件余量充足 |
