## 分工边界（依据《赛题二_环境配置与文件清单》5.1 节 + 本队实际）

| 环节 | 归属 | 本仓库对应物 |
|------|------|--------------|
| MIPI/CSI/DDR2/HDMI 链路、摄像头 I2C、引脚约束、固化 | **嵌入式** | `04_embedded/`（例程工程 `lab_ex1/2/3`） |
| 检测链（HSV→阈值→平滑→质心）、OSD 跟踪叠加、云台控制律/PWM | **视觉** | `03_vision/`（本仓库全部 RTL） |
| 二轴舵机云台机械/供电 | 共同（机械由队内采购） | `05_gimbal/` |

## 全局既定参数（全队遵守，改动需走变更流程）

| 参数 | 值 | 依据 |
|------|-----|------|
| 处理分辨率 | **1280×720@60fps** | 例程已统一为原厂 HD 配置（`代码更新说明.txt`），以工程 `IMG_WIDTH/IMG_HEIGHT` 为唯一事实来源 |
| 图像坐标系 | 原点左上 (0,0)，x 向右，y 向下 | 与 LCD/HDMI 扫描一致 |
| 画面中心 | (640, 360) | 云台误差基准 |
| 目标色 | 红色块（阈值组 0，H∈[335,25]环绕） | 现场可切换 8 组预置 |
| 云台 PWM | 50Hz，脉宽 500~2500µs（软件限位 700~2300µs），上电中位 1500µs | 普通舵机规格 + 安全 |

## 时钟域

| 域 | 频率 | 归属 |
|----|------|------|
| `pix_clk`（检测/OSD） | 74.25MHz（板上是 CSI/AXI 时钟域，仿真用同频） | 嵌入式 PLL 提供 |
| `pwm_clk` | 50MHz（板上有源晶振直供） | 嵌入式 PLL 提供 |
| 跨域 | 全部经本仓库 `pulse_sync.v` / `cdc_4phase.v`，禁止裸跨 | 视觉提供模块 |
