# IF-SERVO-PWM 云台接口（v1.0.0）

## 电气

| 项 | 规格 |
|----|------|
| 输出引脚 | 2 个（PAN/TILT），自 40Pin DC3 扩展 IO 挑空闲脚，`pin.adc` 增约束（嵌入式执行） |
| 电平 | 3.3V LVCMOS（多数舵机可直接识别；舵机多可 5V 供电电平兼容） |
| 极性 | 高电平有效脉冲 |
| 舵机供电 | **独立 5V ≥3A**，与开发板共地、信号线单独走线（高危项：从板载取电会导致画面闪/板复位） |

## 时序（pwm_servo.v，50MHz 域）

| 项 | 值 |
|----|----|
| 周期 | 20ms（50Hz）严格共周期（双路同一计数器） |
| 脉宽 | 500~2500µs ↔ 0~180°；1500µs = 中位 |
| 分辨率 | 1µs（50 拍@50MHz） |
| 上电/复位 | 输出中位 1500µs，直到首个帧拍携带新占空 |
| 软件限位 | gimbal_ctrl 700~2300µs（第一道）+ pwm_servo 500~2500µs（第二道保险） |

## 控制律（gimbal_ctrl.v，每帧一步）

```
err  = invert ? (center − target) : (target − center)     # 像素
step = (err × KP) >>> 8                                    # Q8.8, µs
|err| ≤ DZ（X:25 / Y:20 px）→ step=0（死区）
|step| > SLEW（100µs/帧）→ 截断（限速）
duty = clamp(duty + step, 700, 2300)
```

- 参数：`KP_X=20, KP_Y=18`（Q8.8）、`DZ_X=25, DZ_Y=20`、`SLEW_US=100`、`INVERT_X/Y` 现场整定
- **回路增益核算**：Kp(0.078µs/px) × 舵机(0.18°/µs) × 光学(20.6px/°) ≈ 0.29/帧，
  计及 2 帧检测延迟 ×2 = 0.58 < 1（稳定域）。**Kp=90 的初版经闭环仿真证实发散，勿改回**
- 丢失目标：保持脉宽 + lost_cnt 累加；`I_track_en=0` 时回中位（安全/演示开关）
- 固化要求：以上参数全部为 RTL 参数，随 bit 流固化，冷启动即可跟踪（满足赛道"上电即运行"）

## 校准流程（现场 15 分钟）

1. 通电云台回中，手动把目标放到画面正中，记 OSD 显示的 cx/cy ≈ (640,360)
2. 手动把目标移到画面左侧 1/4 处：若云台向左转 → INVERT_X=1（反极性）
3. 同法校 Y
4. 大幅快速移动目标：观察无持续摆头（若摆头 → 减 Kp 或加 SLEW 限制）
