  ISP AWB 输出=行级突发（每行恰 320 beat，2160 段=3 帧×720 行，无合并/无丢行，
  tlast 精确落行尾）；修复后全链 pixels=2764800/sof=3/eol=2160/drop=0，
  FIFO 最大占用 1601/2048（78%）；LUTRAM 映射成立（bin_smooth 256 dram lut）；

## 使用建议

1. **先上传 PDF 再提问**，并让它先回答 §1.6 的问题——带着具体问题问，回答质量远高于"帮我看看"。
2. 不同模型**分开问、不要混问**；保留各自原始回答。
3. 拿到回答后，逐条与 §1.5 / §8 对照甄别：**要求对方对每条"高"给出最小复现场景**——
   给不出路径的结论一般不可靠（本项目历史上已用此法驳回多条引用幻觉）。
4. 特别欢迎对"已闭环项"的证据型反驳：过去两轮的真 bug（algo mux 首拍、
   ser96to24 突发、悬空网）都是这样被钉出来的。
