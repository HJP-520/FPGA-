# 06_exp_gain_tune —— 曝光/增益现场调节实验版（2026-10-05，A 方案）

## 背景

上板画面"曝光偏重 + 中心泛绿"。源码级排查结论：

- **曝光偏重的根因 = 厂商 demo 的固定曝光/增益默认值**：`ae_set.v` 无闭环 AE，
  默认 `r_ae_set=1991`（≈满帧行时间，注释："最大安全曝光"）、`r_ag_set=144`
  → 厂商自己的增益表 `SC520GainTbl.v` 注释：**144 → 模拟 16× + 数字 1×**。
  正常室内光下 16× 模拟增益必然过曝。
- 原设计把"增益增/减"接在 **40 针扩展口的 N2/J14**（无扩展板=无效）；曝光对儿还被
  `.I_btn({I_button,2'b11})` 屏蔽。板上 K1~K4（D5/A9/B9/C7）在本设计中**未使用**。

## 按键功能与速率（`ae_set.v` 实测推导，时钟 24MHz）

| 按键 | 功能 | 速率 | 参考行程 |
|---|---|---|---|
| **KEY1 (D5)** | 曝光减 | ≈240 步/秒（1 步/4.17ms） | 1991→1000 约 4.1s |
| **KEY2 (A9)** | 曝光加 | 同上 | — |
| **KEY3 (B9)** | **增益减** | ≈7.5 步/秒（1 步/133ms） | 144→80（16×→4×）约 8.5s；→48（2×）约 12.8s |
| **KEY4 (C7)** | 增益加 | 同上 | — |

按住即生效（I2C 实时写传感器寄存器）；松开即停，可反复微调。
**反推公式**（回报用）：`ag ≈ 144 − 7.5×按住秒数`；`ae ≈ 1991 − 240×按住秒数`。
