# 04_awb_framesync —— 第 1 批画质改动：AWB 帧同步化 + tlast 对齐（2026-10-04）

## 目的（源码实证的根因）

上板画面颜色"帧顶跳变/帧内漂移"的结构性根因（外部评审 #1，已逐行核验工程版源码）：

- `awb.v` 在 `I_tuser`（帧首）把 R/B 增益**复位为 1.0**，帧内随累加统计**持续重算**
  → 每帧从"无色偏"渐变到"修正色"，即帧内色彩瞬态；
- 统计只抽 4 像素中的 1 个（`rgb_sum<720` 排除近白），属可保留的抽样策略；
- `isp_top.v` 的 `O_tlast` 直取 awb 的 tlast（在饱和度级之前，与数据错位 3 拍；
  当前 DDR 路径不消费该信号，属"将来踩坑"项，评审 #5）。

## 改动

| 文件 | 改动 |
|---|---|
| `lab_ex1/user_source/hdl_source/awb.v`（板上真值；三处工程源码同哈希） | ① 新增"上一帧统计锁存"（帧内累加 → tuser 锁存；>20480 非白拍才采信，防异常/空帧）；② 除法器输入改用上一帧统计（商帧内恒定）；目标 = `clamp(商, 0.5x~3.0x)`；③ 增益只在帧边界向目标按 **±0.125x/帧** 步进（跨帧平滑），不再每帧复位 |
| `isp_top.v`（同三处） | `O_tlast` 由 `awb_O_tlast` 改为 `sat_O_tlast`（对齐到饱和级之后；repack 未参与 tlast 重排，注释已说明） |

> 设计说明：采用"上一帧统计 → 整帧恒定增益 → 跨帧限速逼近"，天然形成 **2 帧滞后**
> （帧 k 的统计在帧 k+2 起生效）；60fps 下首次修正延迟约 33ms，可接受。

## 验证（仿真先于上板）

**单元 TB（新增）**：`tb_awb.v`（本目录）——直接实例化**工程版** `awb.v`，
喂合成强色偏像素流（帧长 24000 拍 > 阈值），**28/28 CHECK OK → `TB_RESULT: PASS`**：

| 检查组 | 结果 |
|---|---|
| 复位/无统计帧 = 1.0x；首步 ±0.125x；逐帧逼近 1.5x/0.75x 目标 | ✓（F01–F06） |
| **帧内恒定**（帧头/帧尾采样严格相等） | ✓（F06） |
| 换色后 **2 帧滞后**（F09/F10 保持、F11 起爬升） | ✓ |
| **限幅**（3.75x 比值 → 精确停在 3.0x = 0x30000，clamp 失效会到 0x31FFF+） | ✓（F23–F24） |
| **帧中突变不响应**（当帧恒定、下帧保持） | ✓（F25–F26） |

复现：双击 `run_tb.bat`（或 `vlib/vlog -f filelist_awb_tb.f/vsim -c tb_awb`）。

**整链仿真**：保持不动（仿真树用的是另一版独立 AWB 变体）——这样饱和度级的
位精确对拍谱系（baseline_oct03）保持可复现；AWB 行为由上述单元 TB 对**板上真值**验证。
