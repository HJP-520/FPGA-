# 技术文档 —— Step2 颜色识别与质心（检测链）

对应 RTL：`rtl/{hsv_inv_lut.v(生成), rgb2hsv.v, hsv_threshold.v, bin_smooth3x3.v,
centroid_accum.v, detect_top.v}`；金标准：`tools/golden_model.py`；
向量：`tools/gen_vectors.py`。**算术真值以 golden_model.py 为唯一来源**。

## 1. 数据通路

```
96bit AXI-S (4px/beat, AWB 后) ─> ser96to24 ─> rgb2hsv ─> hsv_threshold ─> bin_smooth3x3 ─> centroid_accum ─> 目标包
   (IF-MIPI)                      1ppc 降带宽     2 级流水      1 拍           索引行缓存+3 级        帧末除法
```

总延迟 ~9 拍 + 平滑行缓存；结果在帧末消隐期锁存，不跨帧。

## 2. rgb2hsv（2 级流水，逐位复刻 golden_model.rgb_to_hsv）

- **第 0 拍**：max/min（两级比较树）、delta=max−min、扇区判定（R>G>B 优先级）、
  扇区差值（R 扇区取 G−B，G 取 B−R，B 取 R−G，9bit 有符号）
- **第 1 拍**：`inv = inv_lut[delta]`（256×12 ROM，inv[d]=⌊3840/d⌋）；
  `h = clamp((diff × inv) >>> 6, 0, 60)`（有符号乘 9×13→22bit，算术右移=floor）；
  `H = 扇区基值 + h`（R:0, G:120, B:240）；delta==0 → H=0
- 输出：H 9bit(0..359)、S=delta 8bit、V=max 8bit；valid/sof/eol 随流水延迟

**位精确要点**：Python 侧 `>>` 对负数即 floor，与 Verilog `>>>`（signed）一致；
clamp 只需处理负值（数学上 h ≤ 60 恒成立，代码保留上界 clamp 作保险）。

## 3. hsv_threshold（1 拍）

8 组预置 ROM（case 实现，组号接按键/拨码）：
H 窗口支持环绕（`h_lo>h_hi` 时按或判断——红 335..25）；
`mask = H∈窗 ∧ S≥s_lo ∧ v_lo≤V≤v_hi`。组表与 golden_model.HSV_PRESETS 同源。

## 4. bin_smooth3x3（v7：索引行缓存，最终架构）

- **结构**（选型过程见 01_方案对比，v3~v6 的四种相位 bug 是本步骤主要成本）：
  `line0_arr[x]`=row y−1，`line1_arr[x]`=row y−2；**读写同指针 x**，
  先读旧值（d0/d1 = 上两行当前列）后写新值（line0≤mask、line1≤d0）——
  垂直数据天然对齐，不存在移位延迟线的 ±1 相位问题
- **水平**：每行 2 拍 FF 抽头（x−2, x−1）+ 当拍组合（x）组成 3 列
- **边界复制**：水平 x==0 拍覆写抽头（列 −1 用列 0）；垂直 y==0 三行取当前行、
  y==1 顶中两行取 row0（与 golden 逐位对应）
- **行尾列**：中心 W−1 的窗口在 x==0 拍用抽头寄存器补出
  （{W−2, W−1, W−1复制}，行号回退一行）→ 输出流连续，每行恰 W 个
- 输出：`win ≥ 5 → 1`；O_sof/O_eol 由内部计数器生成，与输出像素严格对齐

**边界语义表**（金标准同款，评审用）：

| 位置 | 语义 |
|------|------|
| 列 −1 / W | 复制列 0 / 列 W−1 |
| 行 −1 / −2（y=0,1）| 复制当前行 / 复制 row0 |

## 5. centroid_accum（帧累加 + 快照除法）

- 累加：count(21b)、sum_x/sum_y(32b)、bbox min/max（seen 标志法）；sof 全清零
- **帧末快照**：`tick_r`（末行 eol 后一拍）时把 sum/cnt/bbox 全部锁存进 snap_* 寄存器，
  除法与结果锁存**只读快照**——下一帧 sof 的清零（比除法早 ~64 拍到达）不再污染本帧结果
  （此 bug 由 tb_centroid 抓出：S_LATCH 读到半截 cnt）
- 除法：恢复法，X/Y 两轴串行各 32 拍；商末位与最后一次移位同拍预测锁存（q_x/q_y）
- 有效性：`snap_cnt ≥ MIN_PIXELS(30)`；无效帧 lost_cnt+1（饱和）
- 输出：68bit 目标包（见 IF-VISION）+ `results_upd`（CDC load）+ `frame_tick`（云台步触发）

## 6. 资源与时序（综合友好性设计）

- 全部 1ppc @74.25MHz，关键路径 = 9 输入加法树 / 9×13 乘法，TD -3 余量充足
- 行缓存 2×1280×1bit → dis-RAM（`ram_style` 属性已标）
- inv LUT 256×12 → Block ROM（case 表由生成器产出，禁止手改）
- 除法器 ~66 拍非流水，仅在消隐期工作，不占像素带宽
