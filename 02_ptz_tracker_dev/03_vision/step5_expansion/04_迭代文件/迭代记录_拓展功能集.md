## #N 帧差运动检测补全验证 + 两处仿真/综合不一致修复（2026-09-20 凌晨，v2 冲刺）

**背景**：motion_detect.v 一直只有 RTL、无 TB 未进回归。补验证时发现两处隐患：

1. **帧边界地址错乱**：帧尾 `row_base += W` 后，下一帧 sof 拍用遗留 row_base 算写地址
   —— 仿真中越界写被忽略（(0,0) 参考停在第 1 帧），综合到 ERAM 地址回绕写 0 号单元。
   仿真/上板行为不一致。**修复**：sof 拍写地址强制 0（该拍像素即 (0,0)，语义正确）。
2. **首帧门控失效**：`started` 在首帧 sof 拍置位，挡不住首帧后续像素——仿真靠未初始化
   RAM 读 X 使 diff 恒假"碰巧"不计，综合 RAM 初值 0 会把首帧误判为全帧运动。
   **修复**：改 `prev_ready`（首帧末行置位），首帧不比对不输出。

**接口语义明确**：每帧末锁存 cnt/bbox 并出 1 拍 O_mot_valid 选通；是否判为运动由
valid=(cnt≥MOT_TH) 表达（亚门限帧照常更新并出选通，下游可清运动指示）。
已知约定：(0,0) 像素每帧只写缓存不比对（sof 拍结构，影响 1/921600）。

**验证**（64x48 × 5 帧，MOT_TH=12）：
- f0 静止背景 → cnt=0 不输出；f1 出现 8x8 块 → cnt=64 bbox(10,10)-(17,17)；
- f2 移动 → cnt=128 bbox(10,10)-(37,27)；f3 消失 → cnt=64 原位置；
- f4 5px 亚门限 → cnt=5 valid=0 bbox(3,5)-(60,44)（正确拒报）。
- tb_motion_detect 进 run_all（第 16 项），期望值由 golden_model.frame_diff_motion 生成。

**教训**：`(* ram_style="block" *)` 阵列在仿真里越界写是"沉默忽略"，综合后是地址回绕
——凡有帧边界滚动地址的模块，帧首拍的地址必须显式覆盖，不能信遗留值。
首帧初始化门控绝不能依赖 X 传播，要用显式状态位。
