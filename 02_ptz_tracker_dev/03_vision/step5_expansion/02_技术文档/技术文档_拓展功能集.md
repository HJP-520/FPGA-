# 技术文档 —— Step5 拓展功能集

对应 RTL：`rtl/{edge_detect_96.v(官方), video_adj.v, motion_detect.v, marquee_rom_64.v(生成)}`；
修改：`detect_top.v(+fid+motion tap)`、`osd_track.v(v2 三行)、`vision_top.v(v2 算法 mux+LED)。

## 1. edge_detect_96（官方 Sobel 边缘检测，复用）

Lab2 的 Sobel 3×3 边缘检测核，灰度对粒度（每 4 像素拍输出 2 个边缘判决，复制到 4 像素）。
端口兼容 isp 链路（96bit AXI-S、tuser/tlast/tready 直通），零适配接入。
输出：边缘 = 白色 FFFFFF，非边缘 = 黑色 000000。
EDGE_TH=80（Lab2 默认），参数化接口已预留。

## 2. algo mux（帧边界平稳切换）

```
algo_q: 帧首拍锁存（I_tvalid && I_tuser 时更新）→ 平稳切换
m_*: algo_q=0 时透传 det_s_*（跟踪视频），=1 时透传 e_s_*（边缘图）
```
切换延迟 ≤ 1 帧（16.7ms），画面无撕裂（帧间不混合）。

## 3. video_adj（亮度/对比度，1 拍流水）

`out = clamp(((c − 128) × C >> 6) + 128 + B)`
C: Q6 无符号 64..192（0.25~3.0 倍）；B: 有符号 −64..+63。
单通道函数复用三通道。apply 于显示路径（OSD 前），检测分支不受影响。
OSD L2 行显示当前值（B±NN C NN）。

## 4. motion_detect（帧差运动检测）

- 前帧缓存：W×H×1bit = 115KB Block RAM
- 同地址读旧写新：`diff = mask ^ prev`
- 帧内累加：cnt + bbox（seen 标志法，同 centroid）
- 首帧 started 门控（prev 未填充时 diff 不可信——仿真 X 与综合 0 行为一致性强制）
- 锁存：末行 eol 后，`mot_valid = cnt ≥ MOT_TH(64)`

## 5. osd_track v2（三行文本 + 跑马灯 + 双框）

| 行 | y 坐标 | 格式 | 内容 |
|----|--------|------|------|
| L1 | 16 | `TRK0 LOCK X0640Y0360` | 算法前缀(TRK/EDG) + 阈值组 + LOCK/LOST + 坐标 |
| L2 | 40 | `D03 B+16 C08 M1839` | 延迟帧数 + 亮度 + 对比度(/8) + 运动计数 |
| L3 | 64 | 跑马灯 | 63 字符消息，2px/帧向左滚动 |

追加：运动包围框（橙色 FF8000，mot_valid 时叠加）。
绘制优先级：L1 > L2 > L3 > 准星 > 目标框 > 运动框 > 底图。

## 6. led_buzzer（声光反馈）

- 锁定：绿灯常亮；丢失：红灯 1Hz 闪烁
- 锁定沿：蜂鸣器 200ms 短鸣
- 全部 GPIO 直驱，参数 BEEP_CYCLES 可调
