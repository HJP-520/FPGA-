# 技术文档 —— Step1 视频链路基座

对应 RTL：`rtl/{ser96to24.v, tpg_720p.v, sim_video_src.v, frame_dump24.v,
pulse_sync.v, cdc_4phase.v}`

## 1. ser96to24（96bit→1ppc 串化器）

- 8 深像素缓冲（数据+sof/eol 标志同址），写 4/拍、读 1/拍，峰值深度 7
- eol 标志挂在每拍第 4 像素（`eol_q[wp+3] <= I_tlast`），sof 挂第 1 像素
- **节拍契约**：输入 beat 占空 1/4（beat 率=像素率/4）→ 缓冲不溢出；
  首版以全速 beat 驱动导致 cnt 超限（$display 断言抓出），TB 与 TPG 均改为
  "4 拍 1 beat + 随机额外空闲"，与真实 CSI/AXI 占空一致
- 读出组合（分布式 RAM 读），O_valid = (cnt≠0)；溢出断言仅仿真

## 2. tpg_720p（测试图案发生器，可综合）

- 1280×720 几何计数器，8 竖条（160px 等宽：灰阶×4、蓝、绿、深绿、深蓝——
  全部避开红色阈值窗，含 H/S/V 三重验证）+ 参数化红块（左上角坐标输入，
  闭环仿真中由 TB 云台模型实时驱动 = 相机在环）
- GAP_EN=1 时 LFSR 插入随机空闲拍（~93% 占空），锻炼下游鲁棒性
- 帧几何：tuser 每帧第一拍、tlast 每行末拍；tb_tpg 断言
  sof 恰 1 次/帧、eol 恰 720 次/帧

## 3. sim_video_src / frame_dump24（仿真专用，禁止综合）

- sim_video_src：回放 chain_beats.hex（96bit 拍）+ chain_flags.hex（tuser/tlast），
  1/4 占空节拍；帧间连续，FRAMES 帧后 #5µs $finish（留末帧除法时间）
- frame_dump24：每帧一文件 `BASE_N.hex`（每行 RGB888 六个 hex 字符），
  MAX_FRAMES 后停止；供 Python 逐像素比对

## 4. pulse_sync / cdc_4phase（全项目 CDC 基础件）

- pulse_sync：toggle + 2FF + 边沿还原；约束源脉冲间隔 > 3 目标钟周期
- cdc_4phase：4 相握手（req/ack 电平翻转式）。
  **正确性关键**（tb_cdc4phase 200 随机数据验证）：源域 `busy` 在
  `ack_2ff == req` 时清除（电平比较，非边沿检测）；数据在 req 翻转前
  稳定、整个握手期保持——跨域采样安全。
  **TB 教训**：驱动侧必须在 load 后 `wait(busy===1)` 再 `wait(busy===0)`，
  否则同沿竞态会丢包（首版 1,3,5,7 丢包即此因）
- 使用规则：目标包/帧拍等每帧一次、低速、准静态信号专用；**禁止**用于像素流
