# 迭代记录 —— Step3 闭环控制

## 迭代 1：tb_gimbal 状态字残留
- 现象：丢失目标帧的 status 死区位残留上一帧值
- 根因：无效分支的 dz/lim 清零用非阻塞赋值，O_status 同拍采样旧值
- 修复：改阻塞；回归 PASS（10 步进表全对，含死区/限速/限幅/丢失保持）

## 迭代 2：tb_pwm 测量竞态与窗口约定
- 现象：v1 任务式同步测得 len=1（仿真器事件调度竞态）；v1.1 计数窗口差一拍（999999/74999）
- 修复：重写为**连续监视器**（自由计数器 + tick 锁存，无任何 @ 事件同步）；
  锁存窗口含 tick 拍本身；换挡载荷避开过渡周期
- 回归 PASS：75000/75000/1,000,000（上电中位）与 60000/100000/1,000,000（新占空）逐拍精确

## 迭代 3：Kp 整定（与 Step4 闭环仿真联动，详见 Step3 方案对比）
- Kp=90/70：闭环发散（θ 跑飞 109°）
- Kp=40/35：慢发散振荡（有效增益 1.16>1）
- **Kp=20/18, SLEW=100：36 帧锁定** ✓（RTL 默认参数与金标准同步更新）
