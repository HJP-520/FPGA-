# 技术文档 —— Step3 闭环控制

对应 RTL：`rtl/{gimbal_ctrl.v, pwm_servo.v}`；金标准：`golden_model.gimbal_ctrl_step`；
系统验证：`tb_closed_loop`（相机-舵机模型在环）。

## 1. gimbal_ctrl（云台控制律，50MHz 域）

单轴单帧步进（双轴独立实例化逻辑，task 复用）：

```
err  = $signed(cx) − CENTER（INVERT 取反）
prod = err × $signed(KP[15:0])          # 29bit 中间量，防截断
s    = prod >>> 8                        # Q8.8 → µs，floor
死区：|err| ≤ DZ → s = 0
限速：|s| > SLEW → s = ±SLEW
nx   = $signed({1'b0, duty}) + s
限幅：nx ∉ [SMIN, SMAX] → clamp 并置 lim 标志
```

- 触发：`I_frame_tick`（每帧 1 拍，pulse_sync 跨域）；输出 O_duty 在同拍寄存
  **新值**（初版曾寄存旧值导致输出滞后一帧，tb_gimbal 抓出）
- 状态字 O_status：[0]dz_x [1]dz_y [2]lost [3]lim_x [4]lim_y —— OSD/调试用
- 丢失目标：duty 保持，lost_cnt 饱和累加；track_en=0 强制回中
- **有符号纪律**：所有误差/乘法/加法显式 `$signed`；task 内中间量 29bit。
  KP 部位选参数值 ≤ 65535 且 ≤ 32767（$signed 扩展安全）

## 2. pwm_servo（双路 50Hz PWM）

- 单周期计数器（1,000,000 拍 @50MHz）+ 双路比较：`pwm = (cnt < duty×50)`
  —— **严格共周期**（两路同计数器，杜绝异周期互拉）
- duty 锁存于 `I_update`（帧拍），内部再 clamp 500~2500µs（第二道保险）
- 上电/复位默认 1500µs（中位）——上电即安全，满足"冷启动直接跟踪"
- tb_pwm（v2 连续监视器）：自由计数器 + tick 锁存，按 tick 序号校验
  上电中位（75000 拍）与新占空（60000/100000 拍）两个完整周期
  —— v1 的任务式 `@(posedge tick)` 同步踩了仿真器调度竞态（len=1），
  连续监视器无事件同步，结构上无竞态

## 3. 参数整定记录（闭环在环仿真，60 帧 × 3 轮）

相机-舵机模型（TB 内行为级，参数均有实物依据）：

```
光学：20 px/°（62.2°FOV @1280px）
舵机：0.18°/µs（180°/1000µs 行程），速率限幅 1.5°/帧（≈90°/s）
延迟：检测+执行 ≈ 2 帧（1 帧检测 + 1 帧执行）
```

| 轮 | 参数 | 结果 | 诊断 |
|----|------|------|------|
| 1 | Kp=90/70, slew=200 | θ 单调跑飞至 109°，duty 打满 | 无符号减法 bug（模型侧）+ 回路增益 1.3>1 |
| 2 | Kp=40/35 | 慢发散振荡（θ 54°±爬升） | 2 帧延迟下有效增益 2×0.58=1.16 仍 >1 |
| **3** | **Kp=20/18, slew=100** | **36 帧锁定（±25px 死区内保持），无极限环**（初版时序） | 有效增益 ≈0.58 <1 ✓ |
| 3b | 同上（2026-10-03 T1 节拍 + T4 周期换装修正后） | **12 帧锁定**（控制滞后 2→1 帧） | 余量更大 ✓ |

**增益公式**（现场换相机/舵机后重算）：
`L ≈ Kp[µs/px] × 0.18[°/µs] × (1280/FOV°)[px/°] × (1+检测延迟帧数)`，要求 L < 1。

## 4. 固化与安全

- 全部参数为 RTL parameter，随 bit 固化 → 冷启动直接跟踪（赛道硬约束）
- 双重限幅（700~2300 + 500~2500）；上电中位；track_en 拨码回中
- 现场整定流程见 IF-SERVO-PWM.md（先极性后增益）
