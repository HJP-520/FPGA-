# 05_gimbal —— 二维矢量舵机云台

## 选型要求（采购/借用）

| 项 | 要求 |
|----|------|
| 类型 | 标准模拟/数字舵机 ×2（PAN+TILT） |
| PWM | 50Hz，500~2500µs ↔ 0~180° |
| 扭矩 | ≥15kg·cm（带动摄像头+支架），金属齿优先 |
| 支架 | 二轴支架，**两轴垂直度与零位一致性**直接决定控制精度 |

## 电气

- 独立 5V ≥3A 稳压供电；与开发板**只共地**
- 信号线 3.3V PWM（40Pin DC3 引出）；舵机延长线按需
- 走线：舵机电源线与 MIPI FPC 分开固定；HDMI 线不参与转动；MIPI FPC 留弯折余量

## 控制接口

- 见 `../06_interfaces/current/IF-SERVO-PWM.md`（50Hz 共周期、500~2500µs、
  软限位 700~2300、上电中位）

## 现场标定流程（15 分钟）

1. 装配后先**手动**扳到两端确认机械行程，再定软限位（防堵转烧舵）
2. 上电回中（1500µs），记录云台朝向 = 画面中心
3. 极性校验：目标移左 → 云台应左转（反了改 INVERT_X）
4. 增益验收：大幅快移目标，无持续摆头（摆头 → 降 Kp 或通知视觉改参数重出 bit）

## 机械装配注意

- 摄像头装 TILT 轴上，PAN 承载全部重量 → PAN 扭矩按总重选
- 重心尽量贴近转轴（减小力矩与振动）
- MIPI FPC 在转动部位留应力环，扎带固定在**静止侧**
