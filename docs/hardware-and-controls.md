# 硬件与操作

## 硬件

目标器件为PH1P35MDG324、速度级-3；SC520CS双Lane MIPI RAW10，DDR2帧缓存，HDMI输出，50MHz系统参考时钟。更换开发板前必须重新核对电平、管脚、时钟和IP配置。

| 信号 | 管脚 | 用途 |
|---|---|---|
| 系统时钟 / 复位 | C4 / R10 | 50MHz / reset |
| SCL / SDA | K3 / J3 | 相机配置 |
| MCLK / PWDNB | L3 / L2 | 相机时钟与控制 |
| K1 K2 K3 K4 | D5 A9 B9 C7 | 低有效按键 |
| SW1 SW2 SW3 SW4 | A4 B4 E11 D11 | 接管与模式 |
| PWM X / PWM Y | C18 / D15 | J2-1 / J2-2 |
| LED1 LED2 LED3 LED4 | D10 E10 C6 D6 | RUN DET LOCK ERR |

完整约束以 `project/user_source/constraints_source/pin.adc` 为准。PWM是控制信号，舵机独立供电并与FPGA共地，电机电流不能由FPGA IO供给。安装方向通过顶层参数核对；当前X角增大向右、Y角增大向上。

## 拨码与四键

下表前三行要求SW1及其他未指定拨码打开。“开/关”按工程逻辑和板卡丝印核对，不靠开关朝向猜测。

| 模式 | 拨码 | K1 | K2 | K3 | K4 |
|---|---|---|---|---|---|
| 追踪 | 仅SW4关 | 红/蓝 | 轨迹 | 坐标轴 | 信息 |
| 灰度 | 仅SW2关 | 线性 | S曲线 | Gamma | 二值化 |
| 边缘 | 仅SW3关 | 原图 | 白叠加 | 黑白轮廓 | 卡通 |
| 原图手动 | 四拨码全开 | 上 | 下 | 左 | 右 |
| 保留效果手动 | 先选效果，再关闭SW1 | 上 | 下 | 左 | 右 |

SW1打开时其他组合回到原图默认逻辑；不能任意组合多个算法模式。

## 手动接管步骤

1. 打开SW1，选择模式和效果；释放按键，等待画面生效。
2. 关闭SW1，释放进入前已经按住的键，再使用四键调整云台。
3. 重新打开SW1并释放全部按键。开关稳定约9.66ms，按键释放保护约19.32ms后恢复模式按键功能；追踪需重新取得有效新结果。

接管保留实际生效配置，取消尚未在帧边界提交的请求。关闭期间改变SW2～SW4不会改变显示，退出后按最终位置提交。上电SW1关闭时保持复位原图；正常离开模式会按RTL复位对应选项，断电不保存配置。

## 云台边界

复位X90°、Y110°，限位X0～180°、Y95～180°。Q3角度单位为1/8°，描述PWM命令，不是机械精度。手动前4周期每周期0.25°，持续保持后每周期0.375°；同轴反向键同时按下抵消。实际视角取决于安装、负载与舵机标定。
