## 二、`01_board_burnpack/` —— 视频通路交付包（已上板）

**来源**：`D:\SC520_display_burnpack`（367 MB）
**定位**：厂商 SC520CS 适配版官方例程 Lab1（1280×720@60fps）的成品比特流 + 完整 TD 工程 + 烧录说明。
**不含**：视觉算法（检测 / OSD / 云台）——那些是这条通路跑通之后才往上挂的。

| 子目录 | 内容 | 说明 |
|---|---|---|
| `00_START_HERE_burn_guide.md` | 烧录与使用说明 | **入口文档**，先读它 |
| `01_bitstream_flash_direct/` | 成品 `.bit` + `.bid` + 一键烧录 `.bat` + QSPI 镜像 | 40 文件 / 24 MB，最常用 |
| `02_TD_project_rebuild/lab_ex1/` | 完整 TD 工程（`user_source/hdl_source`、`ip_source`、约束） | 需要改代码重建时用 |
| `03_simulation_optional/sim/` | ModelSim 整链仿真（虚拟传感器，不需要板子） | 含 `dump2png.py` 导出 PNG |
| `04_codex_validation/` | 2026-10-05 改进版的单测、证据、构建脚本 | 最新一轮工作 |
| `_hx1p35_docs/` | 厂商烧写教程、驱动签名问题、TD 安装教程 | 排障用 |
| `_codex_backup/` | 改进前的 10 个 RTL 备份 | 回退用，勿删 |
| 根目录 PDF | 烧录实战教程（14 页）、评审卷宗（41 页）、使用指导（9 页） | |

### 关键子目录：`04_codex_validation/`

2026-10-05 那一轮改进（重排缓存、AWB 帧边界统计、FIFO 异常恢复、曝光/增益按键）的全部依据：

- `run_validation.py` —— 当前源码的独立验证入口（只依赖本目录 RTL 与 `support/` 模型）
- `build_profile.py --profile {balanced,main,unity,sat_bypass}` —— 隔离重建，不覆盖厂商留档
- `tests/`、`support/` —— 自建 TB 与 ERAM/除法器行为模型
- `evidence/` —— 仿真日志与报告原件
- `changes.diff` + `change_manifest.json` —— 本轮改动差异与前后哈希
- `JTAG_DEBUG_README.md` / `JTAG_BOARD_RESULT.md` —— JTAG 在线调试
- `GREEN_CENTER_RESEARCH.md` —— 「中心泛绿」未结问题的排查记录

> 注：旧文档 `03_simulation_optional/` 的历史脚本仍依赖外部路径；
> 新的当前源码验证走 `04_codex_validation/run_validation.py`。
