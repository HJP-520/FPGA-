## 二、为什么 `02_ptz_tracker_dev/` 算"不能上板"

该目录的 README 写着「整体回归 18/18 全绿」「闭环 12 帧锁定」「OSD 整帧逐位一致」。
这些都是真的，但**全部是 ModelSim 仿真证据**，不是硬件证据。具体说：

1. **算法模块从未进入过真机数据通路。** 上板跑通的是 `08_board_bringup/01_video_passthrough`
   的厂商 ISP 例程（SC520 → demosaic → AWB → HDMI）。这条链路里**没有** HSV 检测、
   没有质心、没有 OSD、没有云台控制。
2. **仿真用的是虚拟传感器。** `sim_video_src.v` / TPG / `tb_*` 的激励是模型或 hex 向量，
   不是真实 MIPI 波形。链路后半段（ISP 行突发节奏）依赖厂商行缓存，实测对气泡敏感。
3. **即便做过综合，资源与时序也只是"预估通过"。** 该目录做过 TD 综合门禁
   （WNS −0.113 → +0.541 ns），但那是**修复 AWB 串化器**之后的链路，不含算法模块。
   算法模块整体挂上去之后的资源占用（ERAM 预算）文档里明确标注为**遗留风险**：
   视觉链 61/108，整合后约 93%，接近上限。

**结论**：`02_ptz_tracker_dev/` 是一套**设计得相当完整、仿真验证扎实，但尚未过硬件检验**的资产。
它的价值在于算法实现与教学材料，而不是可以直接烧板的成品。

## 三、`01_board_burnpack/` 为什么算"已确认能上板"

证据链（按时间）：

1. **2026-10-03** 整链仿真 PASS：`TB_RESULT: PASS frames_dumped=2 tuser_total=3 tlast_total=2008 ser_ovf=0`，
   PNG 出图确认为灰底 + 噪声 + 红色条纹方块（虚拟传感器目标物）。
2. **2026-10-04** SRAM 烧录实测：识别芯片 `PH1P35MDG324` → 下载 **100% / 11.9 秒** → 出图。
   脚本 `burn_camera_sram.bat` 一键无头烧录，已实测。
3. **2026-10-04** 饱和度增强版 K28 重建并**已烧录实测**，画面不发灰。
4. **2026-10-05** JTAG ChipWatcher 板上回读六组探针：
   传感器 ID `0xEE4B`、AWB 样本 230400/230400、MIPI 帧尾计数 57304 且错误位全 0、
   写 FIFO 溢出 0、用户画面反馈"有画面，仍然偏暗"。

**尚未通过的**：画质（偏暗、中心泛绿）。这是**参数与光学问题，不是链路故障** —— 
链路侧的 ID / MIPI / FIFO / DDR 状态位都是干净的。

## 四、当前未结问题

| 问题 | 状态 | 排查记录 |
|---|---|---|
| **画面偏暗** | 未解决 | balanced 版把启动增益从 AG16(1×) 提到 AG80(4×)，仍未上板验证。AE 已到上限 1991，需确认 AE/AG 寄存器实际写入与事务错误位置 |
| **中心泛绿** | 未定位根因 | unity 版（关掉 AWB 与饱和度两级增强）**仍有泛绿**，说明不只是颜色增强所致。需查均匀照明 / 传感器空间色偏 / 显示链路色彩管理。详见 `GREEN_CENTER_RESEARCH.md` |
| **Gamma 未启用** | 仅定义未例化 | `axis_gamma_rgb96` 在通路里只有定义，尚未例化，中间调可能因此偏暗 |
| **QSPI 固化冷启动** | 未验收 | 赛事要求"无 PC 参与"，需现场走完固化并断电重启验证 |
| **ERAM 预算** | 风险 | 算法整体挂载后约 93%，边缘支路可降 512px 或共享串化器腾挪 |
| **厂商 `.al` 打不开** | 已知限制 | TD 6.2.1 GUI 报 `PRJ-8641`，修 4 类 XML 问题仍无效，属版本/格式兼容问题。**不影响成品 .bit**，重编译走"GUI 新建工程挂源码"路线 |

## 五、给验收/答辩的口径

如果被问到"做出来了没有"，稳妥的回答是：

> **基础链路已经上板跑通** —— SC520 摄像头实时取流，经厂商 ISP 链路处理后 720p60 显示到 HDMI 显示器，
> JTAG 回读确认传感器 ID、AWB 统计、MIPI 帧计数、DDR/FIFO 状态位均正常。
> **上层视觉算法（颜色识别、目标质心、OSD 标注、云台闭环）已完成 RTL 实现与逐位精确的仿真验证，
> 但尚未在真机上跑通**，这是我们明确知道的差距，正在做硬件移植。

**不要说**"全部做完了"或"18 项回归全绿所以能上板" —— 回归全绿说的是仿真，与真机是两回事。
